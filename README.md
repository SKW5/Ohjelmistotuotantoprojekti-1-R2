# Student Timetable — JavaFX

Yksinkertainen frontend.

## Käynnistys

Tarvitset JDK 21:n ja Mavenin:

```bash
mvn javafx:run
```

### IntelliJ IDEA:ssa

1. Avaa kansio Maven-projektina.
2. Odota, että riippuvuudet latautuvat.
3. Käynnistä terminaalissa mvn javafx:run
